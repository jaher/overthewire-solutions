Manpage, level one. The goal is the manpage2 password, from /manpage/manpage1: the same strcpy overflow into a 256-byte buffer, but this time a length check fires. If the copy reaches 255 bytes the program raises SIGTERM after the copy, killing the process before the return. The solve is the same shellcode, with the signal disarmed: the exploit parent blocks SIGTERM before launching the binary, the mask is inherited, and the raise never delivers. Then the overflow runs to setresuid seventeen thousand two and execve /bin/sh. I log in as manpage one, read the source, block the signal in the parent, and run the exploit script. The shell comes up as manpage two, and the password file reads back the manpage2 password. The level is solved. I log out.
