Manpage, level three. The goal is the manpage4 password, from /manpage/manpage3: the program compares a stdin line against 256 random bytes read from a password file, and a separate reset binary rewrites that file. The solve is a loop: reset the file, then guess a line that starts with a NUL byte. Strcmp stops at the first NUL, so the comparison matches when the random file itself starts with a NUL. I log in as manpage three, read the source, write the loop in python: reset, then submit a NUL-first line, again and again. When the file's first byte is NUL the comparison passes, the program says wow, you should play the lottery, and spawns a shell. I feed the shell the password command after a delay. The file reads back the manpage4 password. The level is solved. I log out.
