Manpage, level two. The goal is the manpage3 password, from /manpage/manpage2: a getpass-style check against a file, then setuid getuid and an execl where argv zero is the executable and argv one is a marker byte. The trick is that the binary launches whatever argv zero names. I log in as manpage two, read the source, and launch the level with the executable set to /manpage/manpage2 but argv zero set to /bin/sh, with the marker byte as argv one. I plant a script file first: after one wrong guess the binary execs /bin/sh with the marker, which is my script. The script seeks fd three back to zero and reads it, dumping the password: A eight C L K p six I D p. The level is solved. I log out.
