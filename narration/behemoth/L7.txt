The buffer sits five hundred twenty four bytes below the saved frame pointer, so the return address is at offset five hundred twenty eight. We write the shellcode in assembly, assemble it with nasm, and check the bytes. Because the stack address depends on the environment, the exploit sweeps a range of return addresses and looks for the marker the shellcode prints, then reruns with the found address and feeds the shell the commands.
