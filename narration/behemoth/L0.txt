Behemoth, level zero. This is a setuid binary exploitation game, and the first level is a warm-up about reading a binary. We log in as behemoth zero, whose password is simply the account name, and look at the only binary, which is setuid to the next user. We run strings on it and see the program text, plus three strange blobs that look like garbage, and a call to a function called memfrob. That is a glibc function that obfuscates a string by exclusive-oring every byte with the number forty-two. So those blobs are not random; they are the secret with each byte flipped. To recover it, we disassemble main with objdump. The secret is built from three immediate values stored on the stack at successive offsets. Reading each four-byte immediate in little-endian order gives the bytes of the obfuscated string: capital O, capital K, caret, capital G, capital S, capital Y, capital B, capital E, capital X, caret, capital Y. The program then calls memfrob on that string, which flips each byte with forty-two, and compares the result with our input. So we take those raw bytes and exclusive-or each one with forty-two, and out comes the password, eat my shorts. We feed it to the binary; because the shell it spawns reads from the same input, we send the password first and then the commands after a short pause, so the scanf does not eat them. The program prints access granted and gives us a shell as behemoth one. We read the next password and verify it by logging in.
