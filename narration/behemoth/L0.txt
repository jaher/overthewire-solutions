Behemoth, level zero. This is a setuid binary exploitation game, and the first level is a warm-up about reading a binary. We log in as behemoth zero, whose password is simply the account name, and look at the binary with file: it is a setuid, thirty-two bit Intel executable, not stripped. We run strings on it and see the program text, the symbol memfrob, and two short blobs that look like garbage, OK^G and SYBE. memfrob is a glibc function that XORs every byte with forty-two, so those blobs are the password with each byte flipped. XORing those two blobs with forty-two gives eatm and ysho, the start of the password, eatmyshorts. We feed it to the binary; because the shell it spawns reads from the same input, we send the password first and then the commands after a short pause, so the scanf does not eat them. The program prints access granted and gives us a shell as behemoth one. The binary prints the password for behemoth one, and the level is solved.
