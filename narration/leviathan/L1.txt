Leviathan, level one. The home directory holds a setuid binary called check, owned by leviathan two, and the goal is to get leviathan two's password. I log in as leviathan one, on port 2223. I run strings on check, and the readable text gives the game away: the fragments secr and love, the password prompt, and a slash bin slash sh. I trace the program with ltrace, feeding it the word sex, and the trace shows the whole flow: three getchar calls, a strcmp of sex against sex that returns zero, then setreuid and system slash bin slash sh. Then I run check again, piping in sex, then id, then a cat of the leviathan two password file, pausing a second between each line. The shell answers with the leviathan two identity, and the cat prints the password, so the level is solved.
