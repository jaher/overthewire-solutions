Leviathan, level one. The home directory contains a binary called check. Its permissions show the setuid bit and it is owned by leviathan two, which means it runs with leviathan two's privileges. We inspect it with the strings tool, which pulls out readable text from the binary. We see fragments of the password and the prompt, and one of the strings is the word it compares against. Running the program and entering that word satisfies the comparison. The program then switches its effective user identity to leviathan two and starts a shell. Inside that shell we are leviathan two, so we can read leviathan two's password file directly. We verify the password by logging in as leviathan two.
