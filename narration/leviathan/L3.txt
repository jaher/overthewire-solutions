Leviathan, level three. The setuid binary level three asks for a password. Using strings on it reveals the expected value, which is a string of letters that is not a normal word. Disassembling the program confirms the logic: it reads a line, compares it to that hardcoded string, and on a match it sets its effective user to leviathan four and launches a shell. So we run the program, type the string, and we are dropped into a shell as leviathan four. From there we simply read leviathan four's password file. This is the same pattern as before, a hardcoded secret plus a privileged shell, and the lesson is that secrets compiled into a binary are readable with ordinary tools. We verify the password by logging in as leviathan four.
