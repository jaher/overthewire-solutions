Leviathan, level six. The setuid binary leviathan six takes a four-digit code, and if the code is right it spawns a shell as leviathan seven. I log in as leviathan six, on port 2223. Instead of trying all ten thousand codes, I disassemble leviathan six and grep for zero x one b d three, and the one matching line stores that constant as the code to compare against. Zero x one b d three is seven thousand, one hundred and twenty-three in decimal, so I run leviathan six with seven one two three, piping in a cat of the leviathan seven password file. The shell runs the cat and prints the leviathan seven password, so the level is solved.
