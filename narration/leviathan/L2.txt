Leviathan, level two. The setuid binary printfile, owned by leviathan three, prints a file we name, and the goal is to make it print leviathan three's password. I log in as leviathan two, on port 2223. I run strings on printfile and grep for usage, cat, and cant, and the output shows the whole mechanism: a usage line, and a slash bin slash cat format string. I disassemble main, and the listing shows the order of operations: access checks the name we give it, then snprintf builds slash bin slash cat from that name, then the program switches to leviathan three and runs the command with system. The check and the use disagree about the name: access sees one path, but the shell splits it on spaces. So I make a directory, link a to the leviathan three password file, and create a real readable file named a space b. I run printfile on a space b, and the privileged cat prints the password through the symlink, then complains that b is no such file, which proves the argument was split. The password for leviathan three is printed, and the level is solved.
