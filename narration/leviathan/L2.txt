Leviathan, level two. The setuid binary this time is called printfile, and it is owned by leviathan three. It checks a filename with an access call, then builds a shell command that runs cat on that name. Two bugs combine here. The access check is performed with our own identity, so it only passes for files we could already read, but the check and the later cat disagree about the path. We create a symlink named a pointing at the leviathan three password file, and alongside it a real, readable file named a space b. The access check looks at the full name with the space, sees a file we can read, and allows it. But when the program runs cat, the shell splits the name on the space, so cat receives the symlink a, which now resolves with the program's elevated privileges, plus a stray argument b. The password file is printed. We verify the result by logging in as leviathan three.
