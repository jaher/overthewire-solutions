Leviathan, level four. The home directory hides a trash folder containing a setuid binary owned by leviathan five. Running it prints a series of eight-bit binary numbers separated by spaces. Each group of eight bits represents one ASCII character of the password, and the final group is the newline character. So we copy the output and convert each group from binary to its character. Concatenating them reconstructs the password for leviathan five. There is no exploit here, just decoding the output format. We verify the recovered password by logging in as leviathan five.
