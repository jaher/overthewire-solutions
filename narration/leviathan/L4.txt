Leviathan, level four. A setuid binary hides in the dot trash directory, owned by leviathan five, and the goal is to run it to get leviathan five's password. I log in as leviathan four, on port 2223. I list dot trash, and it holds a single file, bin, setuid to leviathan five. I run dot trash slash bin, and it prints eleven eight-bit binary numbers, one per character of the password, ending with the newline group, zero zero zero zero one zero one zero. Each eight-bit group is one ASCII character, so reading them off in order reconstructs the leviathan five password, and the level is solved.
