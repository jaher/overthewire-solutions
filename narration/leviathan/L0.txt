Leviathan, level zero. Leviathan is a classic Unix privilege-escalation game. Each level gives you a way to become the next user. At level zero we log in as leviathan zero with the password leviathan zero. The goal is to find the password for leviathan one, hidden somewhere in the home directory. A normal listing shows only dot files, so we list everything with the all flag, and that reveals a hidden directory called dot backup. Inside it is a bookmarks file exported from a web browser. It is a plain text HTML file, and one of the entries contains the password for leviathan one in its link text. We search the file for the account name, find the entry, and read the password. We then verify it by logging in as leviathan one.
