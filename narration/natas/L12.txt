Natas, level twelve. The task is to upload a JPEG under one kilobyte and get the next password. Reading the source shows the upload handler takes the file extension from a hidden form field that the client controls, called filename. So even though I am uploading a PHP script, I set that field to shell dot php, and first I write the script to a local file: it reads the natas thirteen password file and prints it. I upload it with the filename field set to shell dot php, and the server stores it in the upload directory with a random prefix and returns the path. I request that path, the server runs my code, and it prints the password for natas thirteen, and the level is solved.
