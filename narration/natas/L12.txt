Natas, level twelve. The task is to upload a JPEG under one kilobyte and get the next password. Reading the source shows the upload handler takes the file extension from a hidden form field that the client controls, called filename. So even though we are uploading a PHP script, we set that field to shell dot php. The server stores our file in the upload directory with a random prefix and the extension we chose, and because PHP files are executed by the server, requesting the returned URL runs our code. Our script simply reads the natas thirteen password file and prints it. There is no content check here at all. This is an unrestricted file upload leading to remote code execution. We verify by logging in to natas thirteen.
