Natas, level sixteen. This is the same search box as before, but the filter is stricter: it blocks semicolons, pipes, ampersands, backticks, and both kinds of quotes. I fetch the source and pull out the filter, a preg match against those characters. But the user input is placed inside double quotes in the command, and double quotes do not stop command substitution, so I can still inject a dollar sign followed by parentheses, which the shell evaluates. I test it with a grep on the natas seventeen password file for a matching prefix, and the response is thirteen bytes: empty. Then I test a non-matching prefix, and the response is four hundred sixty thousand bytes: the whole dictionary dumped, because the outer grep ran with an empty pattern. That gives a clear yes or no signal, so I open vim and write a script. The first chunk sets up the request helper, which posts a payload and returns true when the reply block is empty, and starts the loop over the character positions. The next chunk adds the binary search: it asks grep whether the next character falls in the first half of the character set, using a character class, which needs no quotes. The last chunk verifies each character, prints the growing prefix, and stops when the whole password matches. I run the script, and it prints the password one character at a time, finishing with the full thirty-two characters.
