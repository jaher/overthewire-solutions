Natas, level sixteen. This is the same search box as before, but the filter is stricter. It blocks semicolons, pipes, ampersands, backticks, and both kinds of quotes. However, the user input is placed inside double quotes in the command, and double quotes do not stop command substitution. So we can still inject a dollar sign followed by parentheses, which the shell evaluates and substitutes. We put a grep command in there, searching the natas seventeen password file for a pattern. If the pattern matches, the substituted text is the password, and the outer grep searches the dictionary for that password, finds nothing, and prints nothing. If the pattern does not match, the substitution is empty, and the outer grep is run with an empty pattern, which dumps the entire dictionary, a huge response. That gives a clear yes or no signal. Using character classes, which need no quotes, we binary search each character of the password and extract it, then verify by logging in to natas seventeen.
