Natas, level sixteen. This is the same search box as before, but the filter is stricter: it blocks semicolons, pipes, ampersands, backticks, and both kinds of quotes. I fetch the source and pull out the filter, a preg match against those characters. But the user input is placed inside double quotes in the command, and double quotes do not stop command substitution, so I can still inject a dollar sign followed by parentheses, which the shell evaluates. I test it with a grep on the natas seventeen password file for a matching prefix, and the response is thirteen bytes: empty. Then I test a non-matching prefix, and the response is four hundred sixty thousand bytes: the whole dictionary dumped, because the outer grep ran with an empty pattern. That gives a clear yes or no signal: an empty reply means the grep matched, a full dictionary dump means it did not. I open vim and write the script: The first chunk sets up the imports, the page URL, the basic auth header, the character set, and the start of empty, which tests a payload against the page. The second chunk finishes empty: it posts the payload, reads the reply, and returns true when the block between the pre tags is empty. Then it starts the loop over the character positions, with a binary search over the character set. The third chunk adds the binary search: it asks grep whether the next character falls in the first half of the character set, using a character class, which needs no quotes. If the reply is empty, the character is in the first half; otherwise it is in the second. Then it verifies the character with a direct grep, and appends it to the prefix. The last chunk prints the growing prefix and stops when the whole password matches. I run the script, and it prints the password one character at a time, finishing with the full thirty-two characters.
