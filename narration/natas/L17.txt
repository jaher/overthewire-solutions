The only signal we get is timing. The query includes a sleep call only when our injected condition is true, so a response that takes noticeably longer tells us the condition held. This is blind SQL injection through time delays. The approach is the same binary search we used earlier: for each character position, we ask whether the character code is greater than a midpoint, and we wait for the delayed response to answer yes or no. It is slower, because every test costs a deliberate delay, but it still recovers the password character by character. We then verify by logging in to natas eighteen with the recovered password.
