Natas, level nine. The form takes a search term and, according to the source, passes it straight into a shell command that runs grep over a dictionary file. That means our input becomes part of a command line, so shell metacharacters are interpreted. We send a semicolon, which ends the grep command, followed by cat on the natas ten password file, and then a hash character to comment out the rest of the original command. The server runs both commands and prints the output, which includes the password for natas ten. This is operating system command injection, one of the most serious classes of bug, because it lets an attacker run arbitrary commands on the server. We verify by logging in to natas ten.
