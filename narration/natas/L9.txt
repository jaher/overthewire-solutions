Natas, level nine. The form takes a search term and, according to the source, passes it straight into a shell command that runs grep over a dictionary file. I fetch the source and pull out the passthru call, which shows our input going straight into the shell command. That means our input becomes part of a command line, so shell metacharacters are interpreted, and I send a semicolon, which ends the grep command, followed by cat on the natas ten password file, and then a hash character to comment out the rest of the original command. The server runs both commands and prints the output, which includes the password for natas ten, and the level is solved. This is operating system command injection, one of the most serious classes of bug, because it lets an attacker run arbitrary commands on the server.
