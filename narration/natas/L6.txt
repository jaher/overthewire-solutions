Natas, level six. This level has a form that asks for a secret, and it offers to show its own source code. Reading the source, we see it compares our submitted secret against a variable loaded from a file called includes slash secret dot inc. The crucial detail is that this include file lives under the web root and the server serves it as plain text if we request it directly. So we fetch it, and it contains the secret in plain sight. We then submit that value through the form, and the page grants access and prints the password for natas seven. This is a classic case of source code disclosure and an include file exposed over HTTP.
