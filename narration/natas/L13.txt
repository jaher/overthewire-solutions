Natas, level thirteen. Same upload task, but this time the handler validates the upload using a function that checks the file's magic bytes to decide whether it is an image. That check only looks at the beginning of the file, not the whole thing, and it does not look at the extension. So we build a polyglot: we prepend the six byte GIF header, then append our PHP code. The file passes the image type check, and we still set the filename field to shell dot php so it is stored with a PHP extension and executed. Requesting the uploaded file runs our code, which reads the natas fourteen password. The lesson is that prefix-based content sniffing is bypassable and must be paired with strict extension and content validation. We verify by logging in to natas fourteen.
