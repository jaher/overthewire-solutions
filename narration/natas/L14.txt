Natas, level fourteen. We are given a login form backed by a MySQL database, and the source reveals the query is built by concatenating the username and password fields directly into a select statement. That is a textbook SQL injection. We enter a username consisting of a double quote, then or one equals one, then a comment sequence. The quote closes the string literal, the tautology makes the condition always true, and the comment removes the password check entirely. The query returns every row, the application sees a non-empty result, and it prints the password for natas fifteen. The fix would be a prepared statement with bound parameters. We verify the password by logging in to natas fifteen.
