Natas, level two. The page shows almost nothing, just a one pixel image. I fetch the page with curl and grep for the image tag, and it points at files slash pixel dot png, which tells us there is a files directory. The web server has directory indexing turned on for that folder, so requesting the directory itself returns an Apache listing instead of a forbidden page. The listing shows the pixel image and a file called users dot txt. I fetch users dot txt and grep for natas three, and the line gives the password for the next level. The lesson is that unlinked paths can still be found, and open directory indexes expose whatever is sitting there, and the level is solved.
