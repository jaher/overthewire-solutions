Natas, level two. The page shows almost nothing, just a one pixel image. But that image lives at files slash pixel dot png, which tells us there is a files directory. The web server has directory indexing turned on for that folder, so requesting the directory itself returns an Apache listing instead of a forbidden page. The listing shows two entries, the pixel image and a file called users dot txt. That text file is a plain list of usernames and passwords, and one line is for natas three. The lesson is that unlinked paths can still be found, and open directory indexes expose whatever is sitting there. We verify the password by logging in to natas three with it.
