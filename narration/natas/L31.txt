Natas, level thirty-one. The page is a CSV to HTML converter. It checks that a file was uploaded, then takes the parameter named file and loops over it line by line, printing the lines into a table. I fetch the source and grep for the upload, the parameter, the loop, and the split. It checks that a file was uploaded, then takes the file parameter and reads it line by line, splitting each line on commas. The flaw is that the parameter is not guaranteed to be the uploaded file. In a multipart form we can also send a plain text field with the same name. If that plain field comes first in the body, the parameter function returns its value, which we set to the word ARGV. In Perl, opening the special filehandle ARGV means reading the command line arguments. And the CGI library fills the argument list from the query string when the request looks like a keyword list. So if we put a file path in the query string, it becomes an argument, and opening ARGV reads that file. The uploaded file we also send only exists to satisfy the upload check. So I make a small CSV with two rows, a b and c d, and check its contents. I send the plain field file equals ARGV first, then the CSV as the upload, and put slash etc slash hostname in the query string. The table shows the hostname, starting with natas-0, so the read works. Then the same request with the password file in the query string: slash etc slash natas underscore webpass slash natas32. The table shows the password for natas32.
