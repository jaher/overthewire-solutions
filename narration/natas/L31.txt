Natas, level thirty-one. The page is a CSV to HTML converter. It checks that a file was uploaded, then takes the parameter named file and loops over it line by line, printing the lines into a table. The flaw is that the parameter is not guaranteed to be the uploaded file. In a multipart form we can also send a plain text field with the same name. If that plain field comes first in the body, the parameter function returns its value, which we set to the word ARGV. In Perl, opening the special filehandle ARGV means reading the command line arguments. And the CGI library fills the argument list from the query string when the request looks like a keyword list. So if we put a file path in the query string, it becomes an argument, and opening ARGV reads that file. The uploaded file we also send only exists to satisfy the upload check. We first prove it with the hostname file, then read the next password file. The lesson is to validate that a parameter really is an uploaded file handle, and never to let user input name a filehandle for a two-argument open. We read the password and verify it by logging in.
