Natas, level eighteen. The page asks us to log in as admin, but the source shows that the direct admin login is disabled. What it does instead is create a session identifier using a random number between one and six hundred forty, and it stores an admin flag in the session. The credentials are printed only when that flag equals one. The flaw is that the session identifier space is tiny and guessable. So we simply brute-force the session cookie: for every number from one to six hundred forty, we send a request with that value as the PHP session id. Exactly one of those identifiers belongs to a pre-existing admin session. When we hit it, the server loads that session and prints the credentials. The winning identifier is one hundred nineteen. We read the password for natas nineteen and verify it by logging in.
