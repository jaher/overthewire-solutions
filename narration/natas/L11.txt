Natas, level eleven. The site stores your background colour in a cookie, base64 encoded and XOR encrypted with a secret key. The source shows exactly how the encryption works. We know the plaintext for the default cookie, because the JSON structure is visible in the code. By decoding the cookie and XORing it with that known plaintext, we recover the repeating key, which is only four bytes long. Now we can encrypt anything we like. We build a new JSON object with show password set to yes, encrypt it with the recovered key, base64 encode it, and send it as our cookie. The server decrypts it, sees the flag set, and prints the password for natas twelve. This is a keystream recovery attack on a repeating XOR cipher. We verify by logging in to natas twelve.
