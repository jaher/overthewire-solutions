Natas, level eleven. The site stores your background colour in a cookie, base64 encoded and XOR encrypted with a secret key. I fetch the page headers and pull out the cookie, a base64 blob named data. I open vim and write the script. The first chunk imports the helpers, pastes in the cookie, decodes it, and XORs it with the known default plaintext, a JSON object with show password set to no and a white background, which recovers the repeating key, only four bytes long. The second chunk prints the recovered key, builds a new JSON object with show password set to yes, encrypts it with the recovered key, and base64 encodes it into the forged cookie. I run it, and it prints the recovered key and the forged cookie. I send the forged cookie back, and the server decrypts it, sees the flag set, and prints the password for natas twelve, and the level is solved.
