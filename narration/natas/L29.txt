Natas, level twenty-nine. The page lists text files and takes a file name from the query string. The source is hidden, so the first thing we do is recover it through the bug itself. The program appends dot txt to our input and calls the two-argument form of Perl's open. In that form, if the string begins with a pipe character, Perl does not open a file, it opens a pipe to a shell command. So our input becomes a command, and its output goes into the HTTP response. The program also tries to block us: if the input contains the literal word natas, it prints a mocking message instead. But that check is a simple pattern match on the word, and the shell expands wildcards. We can write the pattern as n question mark tas, which matches natas after glob expansion but does not contain the word itself, so the check passes. We first prove execution with the id command and list the directory, then list the password directory using the glob, and finally read the next password file with the same glob trick. The lesson is to never pass user input to a two-argument open, and never rely on substring filters to stop command injection. We read the password and verify it by logging in.
