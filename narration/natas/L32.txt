Natas, level thirty-two. This is the same CSV to HTML code as the previous level, but the page tells us we must prove we have code execution by running a binary that sits in the webroot. The same ARGV injection applies: a plain field named file makes the program open the special handle ARGV, which reads the argument list that the CGI library fills from the query string. But there is a new wrinkle. The CGI library quotes each query word the way a shell would, so a command ending in a pipe character arrives at Perl with a trailing backslash, and it is treated as a filename instead of a pipe. The fix is to end the query with a space and a hash character. The hash comments out the quote and backslash that the library appended, and the pipe stays a pipe. That is why the working query has a hash before the pipe. We list the webroot, find the getpassword binary, confirm with the long listing that it is setuid root and executable by us, and then run it. It prints the password for natas thirty-three. The lesson is that quoting and context matter: the same injection needs a small adjustment depending on how the argument list is constructed. We read the password and verify it by logging in.
