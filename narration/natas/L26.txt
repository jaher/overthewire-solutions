Natas, level twenty-six. The page lets us draw a line and stores the drawing in a cookie. That cookie is base64 encoded serialized PHP, and the page deserializes it without any restriction. The source also defines a logger class. Its constructor writes an initial message into a log file, and its destructor writes an exit message into the same log file when the object is destroyed at the end of the request. The log file path is a private property that comes from the serialized data. This is PHP object injection: because the application has a class with a dangerous destructor, we can rebuild that class from the cookie and choose every property. We start a session first, because the image path includes the session id and we need to know it. Then we build a serialized logger whose log file points to a dot php file inside the image directory, which the web server executes, and whose exit message is PHP code that reads the natas twenty-seven password file. The private property names have to be written with their mangled form, a null byte, the class name, another null byte, and the property name, and each string length must be exact. We send the cookie with the draw parameters. The page deserializes the object, and at the end of the request the destructor writes our code into the image directory. We fetch that file, the server runs it, and it prints the password. The lesson is never to deserialize untrusted input, especially when classes with useful magic methods exist. We read the password and verify it by logging in.
