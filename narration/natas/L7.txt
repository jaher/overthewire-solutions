Natas, level seven. The page has links that pass a page parameter to index dot php, and a hint comment says the password for natas eight is in a specific file under etc. The application takes the page parameter and includes whatever file it names, with no validation. That is a local file inclusion vulnerability. Because the parameter accepts absolute paths, we do not even need directory traversal sequences. We pass the full path of the password file, and the application reads it and prints its contents into the page. That gives us the password for natas eight, which we verify by logging in to natas eight. The lesson is to never let user input choose files to include without a whitelist.
