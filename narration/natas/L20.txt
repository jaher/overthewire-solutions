Natas, level twenty. This level uses a custom session save handler instead of the default PHP serialization. The write handler stores each session variable as a line containing the key, a space, and the value. The read handler rebuilds the session by splitting every line on the first space. The page lets us change a name, which is stored as a session variable. The flaw is that the value is written verbatim, without escaping newlines. So if we submit a name that contains a newline followed by the text admin space one, the session file ends up with a second line reading admin one. On our next request, the read handler parses that line as the session variable admin with the value one. The credentials check sees that admin equals one and prints the password for natas twenty-one. The lesson is that custom serialization must escape the characters it uses as separators, or a value can smuggle in new keys. We read the password and verify it by logging in.
