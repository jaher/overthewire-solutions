Natas, level twenty-three. The page takes a password from the query string and prints the credentials only if two conditions hold at once. First, the string must contain the word iloveyou, checked with strstr. Second, that same string must compare greater than ten. PHP compares a string with a number loosely: it converts the string to a number by reading the leading numeric part and ignoring everything after it. So we put the digits first. The string one zero one one one followed by iloveyou contains the word, and it converts to ten thousand one hundred eleven, which is greater than ten. We try the word alone, which converts to zero and fails. We try the digits first, which succeeds and prints the password for natas twenty-four. We also try the word first, which has no leading digits, converts to zero, and fails. The lesson is type juggling: craft a value so that the string check and the numeric check each see what they need. We read the password and verify it by logging in.
