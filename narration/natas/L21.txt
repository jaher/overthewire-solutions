Natas, level twenty-one. The main page checks a session variable called admin and prints the credentials when it equals one. The page notes that it is colocated with an experimenter site that shares the same session storage. Reading the experimenter's source reveals the flaw: when it receives a submit request, it copies every request parameter directly into the session, so the key and value we send become session variables. Because the two sites share the session store, we can post admin equals one to the experimenter, and that value is written into the shared session. The experimenter returns a session identifier cookie. We then take that same identifier to the main site, which loads the shared session and sees admin equals one. It prints the password for natas twenty-two. The lesson is that sharing sessions between applications is dangerous when one of them lets clients write arbitrary session keys. We read the password and verify it by logging in.
