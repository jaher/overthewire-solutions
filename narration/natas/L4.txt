Natas, level four. The page refuses access, saying we are visiting from an empty referer while authorised users should come only from natas five. I fetch the page and grep for the refusal, and the message names the referer it expects. The referer is just an HTTP header the client supplies, so I fetch the page again, this time adding a referer header claiming we came from the natas five site. The server accepts the header and grants access, printing the password for natas five, and the level is solved.
