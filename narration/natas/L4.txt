Natas, level four. The page refuses access, saying we are visiting from an empty referer while authorised users should come only from natas five. The referer is just an HTTP header, and the client supplies it. It is not a security boundary at all. So we fetch the page again, this time adding a referer header claiming we came from the natas five site. The server accepts the header and grants access, printing the password for natas five. We then verify it by logging in to natas five. The important lesson here is that any header the client controls can be forged, so it must never be trusted for access decisions.
