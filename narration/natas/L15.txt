Natas, level fifteen. This level is a login form backed by a database, and the source shows the username is concatenated straight into the query. The catch is that the page never tells us the password, it only tells us whether a user exists. That makes it blind SQL injection. We first confirm the injection works by appending a condition to the username: a double quote, then and password like percent. The page replies that the user exists, which proves we can test predicates about the password. To read it, we test one character position at a time. We ask the database whether the character code at a given position is greater than a midpoint, and the exists or does not exist reply gives us a single bit. By halving the range each time, we recover each character in about seven requests, and the script walks the whole password to the end. We then verify the result by logging in to natas sixteen with it.
