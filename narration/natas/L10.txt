Natas, level ten. The same grep command injection setup, but this time the application filters the input and rejects semicolons, pipes, and ampersands. I fetch the source and pull out the filter, a preg match against semicolon, pipe, and ampersand. Filtering a few shell metacharacters is not enough, because the unquoted search term is still split into separate shell words, and grep itself accepts multiple files, so I send a caret pattern, then a space, then the path to the natas eleven password file. The shell runs grep with our pattern against both the dictionary and that extra file, and the caret matches every line of the password file, which grep prints prefixed with the filename, and the level is solved.
