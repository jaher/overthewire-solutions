Natas, level ten. The same grep command injection setup, but this time the application filters the input and rejects semicolons, pipes, and ampersands. Filtering a few shell metacharacters is not enough, because the unquoted search term is still split into separate shell words, and grep itself accepts multiple files. We send a caret pattern, then a space, then the path to the natas eleven password file. The shell runs grep with our pattern against both the dictionary and that extra file. The caret matches every line of the password file, and grep prints each matching line prefixed with the filename, including the password for natas eleven. This is argument injection rather than command injection, and it shows why blocklists are fragile. We verify by logging in to natas eleven.
