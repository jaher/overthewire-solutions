Bandit, level twenty-three. A cron job runs every minute as bandit twenty-four and executes every script placed in a spool directory. That directory is world-writable for members of bandit twenty-four's group, so we can drop a file into it. The cron script checks that the file is owned by bandit twenty-three and is a regular file, then runs it, as bandit twenty-four. So we write a short shell script that copies bandit twenty-four's password to a world-readable file in temp, make it executable, and wait for the next minute. When the job fires, our script runs with bandit twenty-four's privileges and the password lands where we can read it. We verify it by logging in as bandit twenty-four. This is a classic scheduled-task privilege escalation.
