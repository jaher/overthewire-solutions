Bandit, level eight. The data file is full of repeated lines, and exactly one line appears only once: that is the password for bandit nine. I log in as bandit8 with ssh bandit8@bandit.labs.overthewire.org -p 2220. Uniq only collapses adjacent duplicates, so the file must be sorted first; I pipe sort into uniq minus u, which prints only lines that occur exactly once. Out comes a single string, the password for bandit nine, and the level is solved.
