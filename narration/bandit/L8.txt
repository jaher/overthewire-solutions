Bandit, level eight. The data file is full of repeated lines, and exactly one line appears only once. That unique line is the password for bandit nine. The natural tool is uniq, but uniq only collapses adjacent duplicates, so the file must be sorted first. We pipe sort into uniq with the minus u flag, which prints only lines that occur exactly once in the sorted input. Out comes a single string, which is the password. Sorting first is the key insight here; without it, duplicates scattered through the file would be counted separately. We verify the password by logging in as bandit nine.
