Bandit, level seventeen. Two files sit in the home directory, one with old passwords and one with new passwords, and the password for bandit eighteen is the single line that changed. The tool for comparing two files line by line is diff. It prints only the differences, and here there is exactly one hunk: line forty-two changed. The old value is marked with a less-than sign, the new value with a greater-than sign. The new side is the password for the next level. We read it from the diff output and verify it by logging in as bandit eighteen. This level is a reminder that diff is one of the most useful tools for spotting exactly what changed between two versions of anything.
