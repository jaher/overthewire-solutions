Bandit, level twenty-nine. The repository looks like a joke. The README just says it is an empty file, and there is nothing interesting in the working tree. But git stores more than files and commits. Tags are separate references, and they can carry their own data or messages. Running git tag lists a single tag named secret. Showing that tag prints its content, which is the password for the next level. So when a repository seems empty, check tags, notes, and other refs, not just files. We verify the password by logging in as bandit thirty.
