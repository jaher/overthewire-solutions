Bandit, level twenty-nine. Another git repository, and this time the master branch's README says no passwords in production. That is a dead end if you only look at the default checkout. But git repositories can have many branches. Listing all branches with the all flag shows a remote development branch called dev, plus a sploits dev branch, neither merged into master. We ask git to show the README directly from the dev branch, and it contains the real password. The lesson is to enumerate everything a repository holds, not just the checked-out branch: other branches often carry secrets that were deliberately left out of production. We verify by logging in as bandit thirty.
