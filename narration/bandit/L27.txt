Bandit, level twenty-seven. The level gives us a git repository served over SSH, hosted under the account bandit twenty-seven git, and tells us that account shares the password we already have. We clone it with git clone and the ssh URL, letting ssh supply the password through the askpass helper. Git pulls the objects and checks out the working tree, which contains a README. Reading the README gives the password for the next level in plain text. We then log in as bandit twenty-eight to verify it. The point is that git over SSH is just another authenticated service, and repositories in these games are often where the next credential is stored.
