Bandit, level twenty-seven. This level is a lesson about git history. We clone the repository, open the README, and find the password has been replaced with a row of x characters. The latest commit is even titled fix info leak, which sounds reassuring. But git keeps every previous version of every file. Listing the log shows the history, and the commit before the fix still contains the real password in plain text. So we ask git to show that older version of the README, and there it is. Removing a secret from the current file does not remove it from the repository's past. We verify the password by logging in as bandit twenty-eight.
