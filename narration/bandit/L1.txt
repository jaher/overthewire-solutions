Bandit, level one. We are logged in as bandit one, and the task is to read the password for bandit two. The catch is that the password file is literally named with a single dash character. That name is special, because most command line tools interpret a bare dash as standard input rather than as a file name. So running cat dash would just sit there waiting on the keyboard. The fix is to make the name unambiguous: prefix it with dot slash, which turns it into an explicit relative path. So we list the directory to see the file, then run cat dot slash dash, and the password prints. We verify it by logging in as bandit two with the value we just read.
