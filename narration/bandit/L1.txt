Bandit, level one. The password for bandit two is in a file whose name is a single dash. I log in as bandit1 with ssh bandit1@bandit.labs.overthewire.org -p 2220. A bare dash is special: most tools read it as standard input, not as a file name, so cat dash would just sit there waiting on the keyboard. I list the directory first, and there it is: a single file named dash. Prefixing the name with dot slash turns it into an explicit relative path, so I run cat dot slash dash. The file prints the password for bandit two, and the level is solved.
