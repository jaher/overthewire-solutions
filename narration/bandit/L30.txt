Bandit, level thirty. The repository's README sets a challenge: push a file called key dot txt containing the phrase May I come in to the master branch. There is a trap. The gitignore file excludes all dot txt files, so a normal git add quietly ignores our file. Using git add with the force flag overrides that rule. We commit the file and push. The push is rejected by a server-side hook, but before rejecting it, the hook validates the content and prints the password for the next level in its remote output. The push failing is the expected outcome; the message is the reward. We verify by logging in as bandit thirty-one.
