Bandit, level thirty. The repository looks like a joke. The README says it is just an empty file, and there is nothing interesting in the working tree or on any branch. But git stores more than files and commits. Tags are separate references, and they can carry their own objects and messages. Running git tag lists a single tag named secret. Showing that tag prints its content, which is the password for the next level. So when a repository seems empty, check tags, notes and other references, not only files. We verify the password by logging in as bandit thirty-one.
