Bandit, level twenty. The home directory holds suconnect, a setuid binary owned by bandit twenty-one: it connects to a port on localhost, sends the current password, and if it matches, it sends back the next password. I log in as bandit20 with ssh bandit20@bandit.labs.overthewire.org -p 2220. So I provide the listener it wants: netcat listening on port four thousand, feeding it bandit twenty's password, then sleeping three seconds to keep the connection open. The listener starts in the background as job one. Then I run suconnect against port four thousand. It reads the password, reports that it matches, and sends the password for bandit twenty-one, and the level is solved.
