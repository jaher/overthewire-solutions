Bandit, level twenty. The home directory has a setuid binary called suconnect, which is owned by bandit twenty-one. When run, it connects to a port on localhost, sends the current password, and if the password matches, it sends back the next password. So we need to provide a listener that knows the right password. We start netcat listening on a port we choose, feeding it bandit twenty's password, then run suconnect against that port. The password matches, and suconnect sends the password for bandit twenty-one over the connection. We verify it by logging in as bandit twenty-one. The important detail is keeping the connection open long enough, which we do by sleeping after sending the password.
