Bandit, level zero. The game hands you the bandit zero password, bandit zero, and the goal is to find the password for bandit one. I log in as bandit0 with ssh bandit0@bandit.labs.overthewire.org -p 2220. The password sits in a file called readme in the home directory, so I run cat readme. The readme congratulates you and points at the rules, and its last line states the password for bandit one. That is the password for bandit one, and the level is solved.
