Bandit, level zero. This is the entry point of the game, and you log in as user bandit zero with the password bandit zero, which the game gives you. The goal is straightforward: find the password for the next level. It is stored in a file called readme, sitting right in the home directory. So we connect over SSH to the game server on port twenty-two twenty, authenticate as bandit zero, and simply run cat readme. The file is readable by this account, so the contents print straight to the terminal. The last line tells us the password for bandit one. To confirm it, we log out and log back in as bandit one with that password. The login succeeds, so the password is correct, and we move on to the next level.
