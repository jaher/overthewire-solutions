Bandit, level two. The password for the next level is in a file whose name contains spaces, and also begins with two dashes. Two separate traps here. The shell splits arguments on whitespace, so an unquoted name becomes several words and cat looks for the wrong files. And the leading dashes look like command options. We handle both by quoting the whole name or escaping each space with a backslash, and by prefixing dot slash so it is clearly a path, not an option. After listing the directory to see the exact name, we run cat with the quoted path and read the password for bandit three. Then we prove it by logging in as bandit three.
