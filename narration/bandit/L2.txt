Bandit, level two. The password for bandit three is in a file whose name contains spaces, and begins with two dashes. I log in as bandit2 with ssh bandit2@bandit.labs.overthewire.org -p 2220. The shell would split an unquoted name on the spaces, and the leading dashes would look like options. I run cat with the whole name quoted, and prefixed with dot slash so it is clearly a path, not an option. The file prints the password for bandit three, and the level is solved.
