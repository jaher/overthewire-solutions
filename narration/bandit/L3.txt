Bandit, level three. The password for bandit four is in a hidden file inside a directory called inhere. I log in as bandit3 with ssh bandit3@bandit.labs.overthewire.org -p 2220. A plain listing hides names that begin with a dot, so I run ls minus l a on inhere. The listing shows dot and dot dot, and one hidden file named with three leading dots: Hiding-From-You. I cat it by its full path, inhere slash dot dot dot Hiding-From-You. It prints the password for bandit four, and the level is solved.
