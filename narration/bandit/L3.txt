Bandit, level three. The password for the next level is stored in a hidden file inside a directory called inhere. The trick is that a normal directory listing hides entries whose names begin with a dot. Running ls with the minus l and minus a flags lists everything, including hidden entries, and reveals a file named with three leading dots, Hiding From You. The file itself is not secret; it is only hidden from casual listings. We cat it by its full path and get the password for bandit four. As always, we confirm it by logging in as bandit four.
