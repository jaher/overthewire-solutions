Bandit, level thirty-two. Logging in as bandit thirty-two drops us into a strange restricted shell. It prints a welcome message and uppercases every command before running it. Ordinary commands simply become garbage. The trick is to use something that uppercasing cannot change. The shell variable zero, written as dollar zero, has no letters, so it survives the transformation, and in a shell it expands to the shell itself. Running it starts a fresh normal shell that inherits the same effective user identity. From there we run id, which reports uid eleven thousand and thirty-three, bandit thirty-three, and then cat the password file for bandit thirty-three. We verify by logging in as bandit thirty-three.
