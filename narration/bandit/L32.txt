Bandit, level thirty-two. Logging in as bandit thirty-two drops us into a strange restricted shell: it uppercases every command before running it. I log in as bandit32 with ssh bandit32@bandit.labs.overthewire.org -p 2220. The note states the trap: the login shell uppercases every command before running it, so ordinary commands become garbage. The trick is to use something uppercasing cannot change: dollar zero has no letters, so it survives, and in a shell it expands to the shell itself. Running it starts a fresh normal shell. From there I run id, which reports uid eleven thousand and thirty-three, bandit thirty-three. Then I cat bandit thirty-three's password file. It prints the password for bandit thirty-three, and the level is solved.
