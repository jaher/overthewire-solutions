Bandit, level fourteen. A daemon is listening on localhost, port thirty thousand. It reads one line and checks whether it is the current level's password; if it matches, it replies with the password for the next level. We connect with netcat and feed it the password. The minus q two option tells netcat to close the connection two seconds after standard input ends, so the exchange finishes cleanly instead of hanging. The daemon answers correct, followed by the password for bandit fifteen. We then verify it by logging in as bandit fifteen. This is a simple service interaction level, and it sets up the pattern for the next few levels.
