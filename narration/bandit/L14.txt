Bandit, level fourteen. A daemon listens on localhost port thirty thousand: send it the current password, and it replies with the password for bandit fifteen. I log in as bandit14 with ssh bandit14@bandit.labs.overthewire.org -p 2220. First I read the current password from its file, slash etc slash bandit underscore pass slash bandit14. Then I feed that password to the daemon with netcat, using a here-string. Minus q two tells netcat to close two seconds after standard input ends, so the exchange finishes cleanly instead of hanging. The daemon answers Correct, followed by the password for bandit fifteen, and the level is solved.
