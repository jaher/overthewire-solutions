Bandit, level twenty-six. We are already inside a shell as bandit twenty-six, reached through the more to vi escape from the previous level. This level is short: the home directory contains a setuid helper called bandit twenty-seven do. Setuid means the program runs with the effective identity of its owner, which here is bandit twenty-seven, so anything we ask it to run runs as bandit twenty-seven. We list the directory to spot the s bit in the permissions and the owner name, then run the helper with cat on the bandit twenty-seven password file. Running cat directly would be permission denied, because bandit twenty-six cannot read that file. Through the helper it prints the password. We then log in as bandit twenty-seven to verify it. The lesson is the same as the earlier setuid level: look for helpers whose owner is the next account.
