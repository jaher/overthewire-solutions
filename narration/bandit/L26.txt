Bandit, level twenty-six. From the shell we escaped to as bandit twenty-six, the next step is a git repository. The task tells us to clone a repository served over SSH, hosted under the user bandit twenty-seven git. We connect with git clone using the ssh URL and authenticate with the password we already have for that account. Git pulls down the objects and checks out the files, including a README. Reading the README gives the password for the next level. We then verify it by logging in as bandit twenty-seven. The point here is that git over SSH is just another authenticated service, and its contents are often the next credential.
