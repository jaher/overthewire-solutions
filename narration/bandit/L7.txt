Bandit, level seven. The password for bandit eight is stored in a data file, on the same line as the word millionth. The file contains many lines, each pairing a word with a value, separated by a tab. All we need is to find the line containing our keyword. grep does exactly that: it prints every line that matches the pattern. Running grep millionth against data dot txt returns a single line, and the value after the tab is the password. It is a good reminder that grep prints the whole matching line, not just the match. We verify by logging in as bandit eight with the extracted value.
