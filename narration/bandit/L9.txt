Bandit, level nine. The password for bandit ten is hidden inside a binary file, stored as human-readable text preceded by several equals signs. The tool strings extracts printable character runs from binary data, ignoring the noise of non-printable bytes. Piping strings into grep for three equals signs narrows the output to the marker lines. The last of those lines reads equals equals password is, followed by the actual password. We read it, then confirm by logging in as bandit ten with that value. This level is about recognizing that binary files often contain embedded plain text, and that strings is the quickest way to surface it.
