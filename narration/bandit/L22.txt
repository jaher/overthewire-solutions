Bandit, level twenty-two. Another cron job copies a password into temp, but this time the file name is computed at runtime, so we cannot just read it from the script. The script takes the output of whoami, which is bandit twenty-three when cron runs it, builds the string I am user bandit twenty-three, hashes it with MD five, and uses the first field as the file name. We can reproduce that exact pipeline ourselves, since the hash is deterministic. Running the same command gives the same MD five name. We then cat that file in temp and read the password for bandit twenty-three. We verify it by logging in as bandit twenty-three. The key idea is reproducing the program's own computation.
