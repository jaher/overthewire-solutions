Bandit, level twelve. The data file is a hexdump of a file compressed again and again, each layer in a different format. I log in as bandit12 with ssh bandit12@bandit.labs.overthewire.org -p 2220. The home directory is not writable, so I make a scratch directory in temp, move into it, and reverse the hexdump with xxd minus r into data dot bin. The plan is to peel one layer at a time, asking file what each layer is: gzip first, then bzip2, then tar. The loop runs up to eight rounds. Each round it checks the current file with file minus b, decompresses with gzip minus d c, bzip2 minus d c, or tar minus x O f as appropriate, and moves the result back to data dot bin; anything else breaks the loop. I cat data dot bin. It prints the password for bandit thirteen, and the level is solved.
