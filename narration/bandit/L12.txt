Bandit, level twelve. This one is a compression puzzle. The data file is a hexdump of a file that has been compressed again and again, with each layer using a different format. The approach is to peel one layer at a time. First we reverse the hexdump with xxd minus r to recover the first binary. Then we ask the file command what it is, and use the matching tool: gzip for gzip, bzip2 for bzip2, and tar to extract archives. Here the chain runs gzip, bzip2, gzip, tar, then a nested tar, then bzip2, tar again, and finally gzip, which yields plain text with the password for bandit thirteen. We do the work in temp, since the home directory is read-only, and verify the password by logging in.
