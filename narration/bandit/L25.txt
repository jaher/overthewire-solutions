Bandit, level twenty-five. The home directory contains the private SSH key for bandit twenty-six, but logging in as bandit twenty-six does not give a shell. Its login shell is a script that runs more on a text file and then exits. The escape is built into more: pressing v opens the file in vi. Inside vi we set the shell variable to bin bash, then run the shell command, which spawns a real bash as bandit twenty-six. There is one catch: the text file is only six lines, so on a normal terminal more exits without ever pausing. We shrink the terminal to about five rows, forcing more to paginate and show its prompt, which is when we press v. From the shell we run the setuid helper bandit twenty-seven do to read bandit twenty-seven's password, then verify it by logging in.
