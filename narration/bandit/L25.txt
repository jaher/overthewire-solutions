Bandit, level twenty-five. The home directory holds the private SSH key for bandit twenty-six, so logging in should be easy. It is not: bandit twenty-six's login shell is not bash, it is a small script that runs the pager more on a text file and then exits. So the login prints a banner and drops you straight back out. The escape is built into more: pressing v opens the current file inside vi, and inside vi we can set the shell variable to bin bash and then run the shell command. That spawns a real bash as bandit twenty-six. There is one catch. The text file is only six lines, so on a normal-height terminal more prints all of it and exits without ever pausing, and we never get the chance to press v. We shrink the terminal to about five rows, which forces more to paginate and show its prompt. Then we press v, land in vi, set the shell, and spawn it. From that shell we cat the password file for bandit twenty-six, then log out and verify the password on a fresh connection.
