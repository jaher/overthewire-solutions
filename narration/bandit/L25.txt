Bandit, level twenty-five. The home directory holds the private SSH key for bandit twenty-six, so logging in should be easy. It is not: bandit twenty-six's login shell is a small script that runs the pager more on a text file, then logs out. I log in as bandit25 with ssh bandit25@bandit.labs.overthewire.org -p 2220. I check the key file: owner-only permissions, twenty-six hundred and two bytes. I cat the key, and the whole private key prints. The login shell is usr bin showtext: it runs more on the home text file, then logs out. There is one catch: the text file is only six lines, so on a normal-height terminal more prints all of it and exits without ever pausing, so I shrink the terminal to about five rows, which forces more to paginate. At the More prompt I press v, which opens the file in vi. In vi I set the shell to bin bash, then run shell, which spawns a real bash as bandit twenty-six. From that shell I cat bandit twenty-six's password file. It prints the password for bandit twenty-six, and the level is solved.
