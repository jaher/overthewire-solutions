Bandit, level fifteen. Same idea as the last level, but the service on localhost port thirty thousand and one expects a TLS connection. I log in as bandit15 with ssh bandit15@bandit.labs.overthewire.org -p 2220. Plain netcat will not work, because the daemon waits for a TLS handshake before it reads anything, so I use openssl s client, which performs the handshake. I pipe the current password into openssl s client, connecting to localhost port thirty thousand and one, with the quiet flag. OpenSSL prints certificate chatter about a self-signed certificate, then the daemon answers Correct. The next line is the password for bandit sixteen, and the level is solved.
