Bandit, level twenty-eight. Another git repository, and this time the master branch's README says no passwords in production. That is a dead end, but git repositories can have many branches. Listing all branches shows a remote development branch called dev, which was never merged into master. We ask git to show that branch's README directly, and it contains the real password. The lesson is to enumerate everything a repository holds, not just the default checkout: other branches often carry secrets that were left out of production. We verify by logging in as bandit twenty-nine.
