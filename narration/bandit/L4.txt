Bandit, level four. The inhere directory contains ten files, all with similar dash-prefixed names, and exactly one of them holds human-readable text. The others are binary garbage. The tool for this is file, which inspects a file's magic bytes rather than trusting its name. Running file across the whole directory prints a classification for each entry. Nine come back as raw data, and one, file zero seven, is reported as ASCII text. That is our target. Because the name starts with a dash, we pass it with the directory prefix, inhere slash dash file zero seven. Reading it gives the password for bandit five, which we verify by logging in.
