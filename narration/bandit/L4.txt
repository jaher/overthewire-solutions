Bandit, level four. The inhere directory holds ten files with similar dash-prefixed names, and exactly one of them is human-readable text. I log in as bandit4 with ssh bandit4@bandit.labs.overthewire.org -p 2220. The file command inspects magic bytes instead of trusting names, so I run file on every file in inhere. Seven come back as data, two as non-ISO extended ASCII text, and one, file zero seven, as ASCII text. Because the name starts with a dash, I pass it with the directory prefix: cat inhere slash dash file zero seven. It prints the password for bandit five, and the level is solved.
