Bandit, level eighteen. The password is in a readme file, but there is a twist: logging in interactively immediately logs you out. The account's shell startup script terminates the session before you can type a command. The workaround is to avoid an interactive shell entirely. Instead of opening a session and typing, we pass the command as an argument to ssh, so the server runs cat readme and returns the output without ever starting the interactive shell that would kill the connection. We read the password for bandit nineteen and verify it by logging in as bandit nineteen. The lesson is that SSH can run a single command remotely, which is often more reliable than an interactive session.
