Bandit, level nineteen. The home directory contains a binary called bandit twenty do, and its permissions show the setuid bit, with bandit twenty as the owner. That means when the program runs, it runs with bandit twenty's effective user ID, not ours. The program simply executes whatever command you give it as arguments, under that elevated identity. So we run it with cat, targeting the password file for bandit twenty. Because the command executes as bandit twenty, it can read a file that our own account cannot. The password prints, and we verify it by logging in as bandit twenty. This level is a clean demonstration of how a setuid helper can be abused if it executes arbitrary commands.
