Bandit, level twenty-one. The next password is delivered by a scheduled job. Cron definitions live in etc cron dot d, and there we find a job that runs every minute as bandit twenty-two. Its script does two things: it makes a file in temp world-readable, then copies bandit twenty-two's password into that file. Because the script runs as bandit twenty-two, it can read the protected password file, and the chmod makes the copy readable by us. So we read the cron definition, read the script to learn the file name, and then cat the output file. Out comes the password for bandit twenty-two. We verify it by logging in as bandit twenty-two. The lesson is to check scheduled jobs when hunting for credentials.
