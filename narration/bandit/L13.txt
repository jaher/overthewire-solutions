Bandit, level thirteen. The home directory contains a private SSH key. That key is the credential for bandit fourteen: the matching public key is installed in bandit fourteen's authorized keys. Normally the level suggests using the key to SSH to localhost from inside the game server, but the lab blocks connections from localhost, so that route fails. Instead we fetch the key file over our authenticated session, save it locally, lock its permissions down to owner-only, and use ssh with the minus i flag to connect to the public host as bandit fourteen. The key proves our identity, and we read bandit fourteen's password directly. We verify it by logging in as bandit fourteen with that password.
