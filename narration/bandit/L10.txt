Bandit, level ten. The data file contains base64 encoded text, and the password is what you get after decoding it. Base64 is just a reversible encoding that maps bytes into a safe ASCII alphabet; it is not encryption. The base64 command with the minus d flag decodes it back. The decoded output reads the password is, followed by the string. We take that value and verify it by logging in as bandit eleven. Nothing more to it, but it is worth remembering that base64 shows up constantly in web tokens and configuration files, so recognizing it at a glance is a useful habit.
