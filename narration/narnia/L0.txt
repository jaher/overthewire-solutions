Narnia, level zero. This is the buffer overflow wargame, and the first level is the classic warm-up. The source shows a local variable, val, initialised to 0x41414141, and a twenty-byte character buffer that the program fills with scanf, reading up to twenty-four characters. Then it compares val with 0xdeadbeef. If they match, it switches to the next level's user and gives us a shell. The bug is the twenty-four character limit: scanf writes up to twenty-four bytes into a twenty-byte buffer, so the last four bytes spill over into val, which sits right after the buffer on the stack. We send twenty filler characters, then the four bytes that spell deadbeef in little-endian order: ef, be, ad, de. The comparison now succeeds and the program hands us a shell as narnia one. We check it with id, read the password file for narnia one, and then log in as narnia one to prove the password is real. Notice the discipline we keep for every level: derive the password live, then verify it by logging in as the next account.
