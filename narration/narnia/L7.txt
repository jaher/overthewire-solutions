Narnia, level seven. The vulnerable function declares a buffer of one hundred twenty-eight bytes and a function pointer called ptrf, initialised to goodfunction. It prints the addresses of goodfunction and hackedfunction, and the address of ptrf itself. Then it calls snprintf with the buffer, the size one hundred twenty-eight, and argv one as the format string. Finally it calls ptrf. If ptrf points at hackedfunction, we get a shell. The key structural fact is that ptrf sits just below the buffer on the stack, at ebp minus one hundred thirty-two, while the buffer starts at ebp minus one hundred twenty-eight. Writing forward into the buffer can never reach ptrf, so this is not an overflow level. The only tool is the format string, and percent n can write to any address we place in the argument list. We inspect the layout in gdb at the snprintf call. The stack shows the destination buffer pointer, the size, the format string pointer, and then the first vararg, which is the current value of ptrf. The next two varargs are the first and ninth four-byte words of the destination buffer. The format string itself, argv one, lives far up the stack. To find where its bytes are readable as an argument, we sweep candidate argument indices. For each candidate we first probe the address of ptrf with an argument of exactly the same length as the payload, because the stack position depends on the argument length, then run the real payload and look for the success message. The winning index is one hundred fifty-two. The payload starts with the address of ptrf plus two, then the address of ptrf. Those eight bytes are read as arguments one hundred fifty-two and one hundred fifty-three. After printing eight characters, percent c with a width pads the output to the high half of hackedfunction, and percent one fifty-two dollar h n writes that high half into ptrf. Then another padded percent c brings the count to the low half, and percent one fifty-three dollar h n writes the low half. snprintf stops copying at one hundred twenty-eight bytes, but percent n still fires with the full count, so the large widths are fine. The program prints Way to go, runs a shell as narnia eight, and we read the password and verify it by logging in.
