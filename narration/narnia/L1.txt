I open vim and write a Python driver. The shellcode is written out as raw bytes: it builds the path to the shell on the stack and calls execve, syscall eleven. Every byte is chosen to avoid a null, because the environment cannot carry one. The driver builds the payload as two hundred NOPs, then the shellcode, then four more NOPs, then a candidate address in little-endian. It sweeps that address from ffff d zero zero zero up to ffff e zero zero zero, four bytes at a time, skipping any payload that contains a null byte, and skipping any run that times out. For each candidate it sets EGG through the environment, decoding the bytes as latin one so the high bytes survive Python's text encoding. It reads the shell commands from standard input, and when the output contains uid equals, it prints the output and stops. I print the finished driver with cat, to check it.
