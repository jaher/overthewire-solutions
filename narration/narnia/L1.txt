Narnia, level one. The program takes the environment variable EGG, casts it to a function pointer, and calls it, so whatever bytes we put in EGG run as machine code. I log in as narnia one and read the source. The main function checks that EGG is set, prints trying to execute EGG, and calls it. I print the main function again with sed. I open vim and write a Python driver. The driver starts with the imports, then the shellcode opens: push a zero, then push slash slash s h, the first half of the shell path. The rest of the shellcode pushes slash bin, sets ebx to the stack, builds the argument array, and calls execve, syscall eleven — every byte chosen to avoid a null, because the environment cannot carry one. Then the payload builder: two hundred NOPs, the shellcode, four more NOPs, and the candidate address in little-endian; main reads the shell commands from standard input and sweeps the address from ffff d zero zero zero up to ffff e zero zero zero, four bytes at a time. For each candidate it skips any payload containing a null byte, sets EGG through the environment, decoding the bytes as latin one so the high bytes survive, and runs the target with a five second timeout. A run that times out is skipped; when the output contains uid equals, it prints the output and the hit address, and stops. I run the driver, piping in id and the password read. The program prints trying to execute EGG, the shell comes up as narnia two, and the password file prints the next password. The shell runs as narnia two, and the level is solved.
