Vortex, level zero. This one never gives you a shell at all: it is a network service listening on port 5842 of vortex.labs.overthewire.org. The official description says the service sends four unsigned integers in host byte order, you add them up and send the sum back, and the reply contains the username and password for vortex one. The machine is 32 bit x86, so host byte order means little endian. I open vim and write a small C client: create a TCP socket, resolve the host name, connect to port 5842, read sixteen bytes, copy them into four unsigned integers, add them, write the four byte sum back, then read until the service closes and print the reply. The first bug I hit was using inet_pton on a host name, which only accepts a literal address, so I switched to gethostbyname; the compiler also caught a missing netdb header. The reply arrives split across reads, and my input buffer was only sixteen bytes, so I read into a separate two hundred and fifty six byte buffer until the peer closes. Then I compile with gcc, run it, and the service answers with the vortex one credentials. I verify by logging in over SSH on port 2228, and the password is real.
