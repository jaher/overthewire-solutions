Vortex, level zero. This one never gives you a shell at all: it is a network service listening on port 5842 of vortex.labs.overthewire.org. The official description says the service sends four unsigned integers in host byte order, you add them up and send the sum back, and the reply contains the username and password for vortex one. The machine is 32 bit x86, so host byte order means little endian. I open vim and write a small C client, starting with the headers: The headers: standard I/O, string, and unistd, then the socket headers, sys/socket, netinet/in, and arpa/inet, plus netdb for looking up host names. Then main: the declarations — a descriptor and counter, a sockaddr_in, a sixteen byte buffer, a two hundred fifty six byte reply buffer, four unsigned integers and a sum, a byte count — and then the TCP socket, created with socket, stream, zero, with an error check. Next I set up the address: zero the structure, set the family to AF_INET and the port to 5842, then resolve the host name with gethostbyname and copy the address in. Then I connect the socket to that address, with an error check. Then the read loop: keep reading until sixteen bytes have arrived, accumulating the count, and bail on any read error. Then the decode: copy each four byte group into an unsigned integer, add it to the sum, and print the four values and the sum. Then I write the four byte sum back to the service. Finally the reply loop: read into the two hundred fifty six byte buffer until the service closes, print the reply, close the socket, and return zero. The first bug I hit was using inet_pton on a host name, which only accepts a literal address, so I switched to gethostbyname; the compiler also caught a missing netdb header. The reply arrives split across reads, and my input buffer was only sixteen bytes, so I read into a separate two hundred and fifty six byte buffer until the peer closes. Then I compile with gcc, run it, and the service answers with the vortex one credentials. The service prints the vortex one username and password, and the level is solved.
