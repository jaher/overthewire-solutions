Vortex, level ten. The goal is the vortex11 password, from /vortex/vortex10: a setuid vortex11 binary that seeds rand with a time-based value, skips that many draws, prints a twenty-value window of rand output, and gives up a shell when the four bytes read from standard input equal the exact seed. The seed is never printed, but the window is, and glibc's rand is deterministic given the seed, so the solve is to reverse the seed from the printed window. I log in as vortex10. I make a working directory, move in, and copy the binary. The gate first: the level prints the window and waits thirty seconds for the four raw bytes. objdump shows main: times, clock, and time feed the base, a signed mod makes the skip count, srand seeds the generator, the loop skips the draws, and the window prints twenty values. The GOT shows srand, rand, times, clock, and execlp, and readelf shows the stack read-write, no shellcode. I open vim and write the cracker: it uses the target's own libc, because emulating glibc's TYPE three rand in python failed for this build. First the imports and the window, twenty values read as hex from the command line. Then the sweep: for every candidate seed, time plus or minus six hundred seconds, and every skip count zero through five hundred, srand of the candidate, that many draws skipped, and the next twenty compared against the window. A twenty-value match is two to the minus one-sixty, so the hit is exact. The file is 28 lines, 892 bytes. I open vim and write the solver: it runs the level, parses the window, cracks the seed, and answers. The file is 29 lines, 1033 bytes. I run it: the window prints, the cracker reports FOUND with the seed, one seven nine four eight three nine four eight four, and the skip, three hundred sixty-six, the four raw bytes go back, and the spawned shell runs id and a read of the password file. The response prints uid five thousand eleven, vortex11, and the password, x b four capital D capital V capital Z two a v. I log out of vortex10. Then I log in as vortex11 with that password. id confirms uid five thousand eleven, vortex11. And the password file reads back the same password. The level is solved. I log out.
