Vortex, level five. The goal is the vortex6 password, from /vortex/vortex5: a setuid vortex6 binary that hashes the getpass input with glibc's MD5 and compares sixteen bytes against a fixed digest, and gives up a shell when they match. The gate is the exact password, and the target hash is the MD5 of the password itself, so the solve is a preimage crack. I log in as vortex5. I make /tmp/l5rec, move in, and clear any old files. I open vim and write the cracker: it forks twenty workers over the alphanumeric space, each checking one first letter, for lengths one through five, hashing each candidate and comparing to the target digest. First the imports and the target: the digest read as bytes from hex, one five five f b nine five d, and the alphabet, letters plus digits. Then the worker: the short lengths loop, then the five-character space, this first letter plus four more, and hashlib's md5 of each candidate against the target. Then the pool: twenty processes, the first hit printed as FOUND, and the pool terminated. The file is 29 lines, 924 bytes. I log out of the shell. Back on my own shell, I make a local directory and open vim on the cracker there. Vim warns about a swap file left by an earlier edit session; I open anyway. It is the same twenty-worker search, typed out again to run locally. The local copy is 29 lines, the run finds the five-character password, and the hash checks out. I log back in as vortex5 and run the level directly, /vortex/vortex5, typing the cracked password at the getpass prompt.
