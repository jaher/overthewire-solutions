Vortex, level three. The goal is the vortex4 password, from /vortex/vortex3: a setuid root binary that copies our argument into a 128 byte stack buffer, then writes the buffer's address through a pointer we control, and exits. The pointer only has to look like 0x0804-something, and the stack is executable — so if we point it at exit's own GOT slot, the exit call jumps straight into our shellcode on the stack. I log in as vortex3. I make /tmp/l3rec, move in, and clear any old files. I open vim and write the shellcode in assembly: it opens the password file, reads it, and writes it to standard output. First the path, built backwards on the stack: zero eax, push a zero to terminate the string, then push the pieces of /etc/vortex_pass/vortex4. Then the open call: the stack pointer becomes the path, ecx is zeroed, eax is 5, and int 0x80 opens the file. Then the read: the descriptor moves to ebx, eax is 3, ecx points at the stack, edx is 100 bytes, and int 0x80 reads the password onto the stack. Then the write: eax is 4, ebx is 1 for standard output, ecx still points at the stack, and int 0x80 prints it. Finally exit: eax is 1, ebx is zero, int 0x80. The file is 28 lines, 433 bytes. nasm assembles it to 69 bytes. The hex dump shows the shellcode as one line of hex. The count comes back zero, and the fallback prints NO-NUL-BYTES: the shellcode has no zero bytes, so it survives strcpy. I open vim and write the driver: it reads a file and passes its whole contents as the binary's argument. The includes, then main: a 4096 byte static buffer, and fopen of the file named on the command line. It reads the file into the buffer, then builds the argument list — the binary's path, the buffer, and a null — and execs it, returning 51 if exec ever comes back. The driver is 6 lines, 247 bytes. I compile it — no output means no errors. Then I build the payload: the 69 byte shellcode, A filler to offset 128, four more As for the lp slot, and 52 90 04 08 in the lpp slot — 136 bytes in all. The payload file is 136 bytes. I run it, and the shellcode prints the vortex4 password. I log out of vortex3. Then I log in as vortex4 with the password the shellcode printed. id confirms uid 5004, vortex4. And the password file reads back the same password. The level is solved. I log out.
