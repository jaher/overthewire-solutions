Maze, level zero. The goal is the maze1 password, from /maze/maze0: a binary that checks a path is readable with access, then drops to that uid and opens the same path to print it. The path is a fixed name in /tmp, a long md5-looking string. This is a check-then-open race. I log in as maze zero. I read the binary: the check and the open are two separate steps, so the file at that path can change in between. I place a readable file full of A's at my own path, and a symlink from the level's path to /etc/maze_pass/maze1. Then a C loop renames the level's path back and forth between the readable file and the symlink, thousands of times, while I run the level in a loop. Most runs see the readable file and print A's. Some runs pass the access check on the readable file and open the symlink instead: the A-prefix lines in the count are the partial wins where the filler leaked into the read buffer before the swap. Eight hundred and fifty-three clean winning runs out of one thousand two hundred and seven, plus the A-prefixed partials: the maze one password is S p five V m L G F C zero. The level is solved. I log out.
