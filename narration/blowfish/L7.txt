Blowfish, level seven. The goal is the level8 password from /levels/level7: the source shows the overflow, and this time the answer is return-to-libc rather than raw shellcode. objdump around the vulnerable call shows the buffer and the return, the randomization check reads zero, and the process maps confirm where libc loads. nm on the libc dynamic symbols pins the exact addresses of system, setuid, and strcpy. I open vim and write the exploit: the payload overflows the return address into system with a command string that cats the pass file, chained with setuid so the shell keeps the rights it needs. The run returns into system, the command executes, and the pass file reads g zero zero d underscore j zero b's successor: w three l l underscore d zero n three exclamation. The level is solved.
