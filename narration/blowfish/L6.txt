Blowfish, level six. The goal is the level7 password from /levels/level6: a badfunc with an overflow the source still shows, but this build needs a jmp esp trampoline instead of a fixed address. objdump on badfunc shows the overflow, the randomization check reads zero, and ldd confirms the libc this binary binds. I open vim and write the shellcode: forty-one bytes that read the pass file and write it out, no zero bytes. nasm assembles it and objcopy extracts the binary. I open vim and write findjmp: it scans the loaded libc for a jmp esp byte pair and prints the first hit. The scan reports the trampoline address. I open vim and write the exploit: the payload pads to the return slot, drops in the trampoline, and follows it with the shellcode. The run lands, the shellcode reads the file, and the password ur_so_l33t's successor comes back: g zero zero d underscore j zero b. The level is solved.
