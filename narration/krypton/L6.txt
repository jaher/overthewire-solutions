Krypton, level six. Here the encryption mixes a secret key with a pseudo-random keystream, and the hint says the generator is weak. I log in as krypton six, and read the second hint: eight bit LFSR. A feedback register like that is deterministic, so its output repeats, and a chosen plaintext can expose it. I make a working directory in temp, open it up, and link the key file into it. Then I write six hundred A's into a file: with A as the plaintext, each output byte is just the keystream offset, no plaintext mixed in. I run the encrypt program on it. Then I run the solver, which reads the keystream back, finds its period, and decrypts the target with the repeating offsets. The offsets repeat every thirty letters, and the target decrypts to LFSR IS NOT RANDOM, the password for krypton seven. An LFSR is not a random source.
