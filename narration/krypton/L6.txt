Krypton, level six. Here the encryption program combines a secret ten-byte key with a pseudo random keystream from a weak generator, and the hint tells us it is an eight-bit linear feedback shift register. Disassembling the program shows exactly how each character is produced: the plaintext letter plus a key byte plus a generator byte, all modulo twenty-six, and the generator advances once per output letter. Because the generator is deterministic and periodic, we can mount a chosen plaintext attack. We encrypt a long run of the letter A, subtract A from each output, and the result is the combined periodic offset. It repeats with a period of thirty. We then decrypt the target file using that periodic offset and recover the password, LFSR is not random. We verify by logging in as krypton seven.
