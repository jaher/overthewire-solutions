Krypton, level zero. Krypton is the cryptography wargame, and it starts gently: the level page itself hands us the first credential, a string it says encodes the password in Base64. Base64 is not encryption, it is just an encoding that turns bytes into a safe alphabet, so decoding the string gives back the original bytes. I echo the string and pipe it through base64 minus d, and out comes KRYPTON IS GREAT, the password for krypton one. There is no cryptanalysis yet; this level just shows that encoded is not the same as secret.
