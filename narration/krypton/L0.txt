Krypton, level zero. Krypton is the cryptography wargame, and it starts gently. The level page itself hands us the first credential: a string that it says encodes the password in Base64. Base64 is not encryption, it is just an encoding that turns bytes into a safe alphabet. So we take the string, pipe it through the base64 decoder, and out comes the password for krypton one. We then verify it by logging in as krypton one. There is no cryptanalysis yet; this level is simply here to set up the account and show that encoded is not the same as secret.
