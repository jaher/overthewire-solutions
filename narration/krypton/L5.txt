Krypton, level five. Another Vigenere cipher, but now the key length is unknown. The first step is to find it, and frequency analysis can still break it. I log in as krypton five, and read the README: one last polyalphabetic cipher, this time with the key length unknown. I need the three intercepted messages as files, so I open vim and write the first ciphertext into a file. one long line of five-letter groups. The first file is seventeen hundred and seventy-seven bytes. The second message gets the same treatment: I open vim and write its ciphertext into a second file. another long line of five-letter groups. The second file is nineteen hundred and sixteen bytes. And the third message the same way: I open vim and write its ciphertext into a third file. a third long line of five-letter groups. The third file is twenty-one hundred and eleven bytes. Then I read the target: BELOS Z, six letters. Now I write the solver. I open vim and type it in: The imports: re for the letter filter, and Counter for the tallies. The header comment states the idea: shift the text by k and line it up with itself, and when k is a multiple of the key length the same key letters meet, so the index of coincidence jumps to English level. Then the English letter frequency table the scoring measures against. It strips each file down to just its capital letters, then defines the index of coincidence: how uneven a letter distribution is. Each column is then a Caesar cipher, broken the same way as last level: try all twenty-six shifts and keep the one that best matches English frequencies. Decoding subtracts the key letter at each position, cycling with the key. The main part loads the three files and prints each one's letter count and index of coincidence. Then it scans key lengths from two to twelve, averaging the column index across all three messages, takes the winner, recovers the key from the first file's columns, and prints the decoded target. I run it. Each file is around fifteen hundred letters with an index of coincidence near zero point zero four: flat, polyalphabetic, as expected. The vote peaks at nine, zero point zero six five nine, ahead of twelve and six, so the key is nine letters. The key is KEYLENGTH, and the target decodes straight to RANDOM, the password for krypton six. Three messages, one key length, one key: the index of coincidence found the length, and frequency analysis found the letters.
