Krypton, level two. This time the cipher is a Caesar cipher, a fixed shift, but we do not know the shift and cannot read the keyfile. However, we are given a setuid program that encrypts any file we provide. So we do a chosen plaintext attack: we encrypt the whole alphabet. The output shows that A maps to M, which is a shift of twelve, not the thirteen you might assume. To decrypt the target we therefore shift by minus twelve. We set up a working directory in temp, link the keyfile into it, give the setuid program permission to use the directory, and run it. The decrypted password is caesar is easy. We verify by logging in as krypton three.
