Krypton, level two. This time the cipher is a Caesar cipher, a fixed shift, but we do not know the shift, and the key file is unreadable. There is an encrypt program that reads the key file and encrypts any file we hand it, so we can use it as an oracle. I log in as krypton two, and read the target: OMQEMDUEQMEK, twelve letters, no spaces. First I make a working directory in temp and move into it, then I link the key file into it and open the directory up, so the encrypt program can reach the key. I open vim and write the whole alphabet into p dot txt, as a chosen plaintext: then the second half, completing the alphabet. Then I run the encrypt program on it and read the ciphertext file, and the output is MNOPQRSTUVWXYZABCDEFGHIJKL: A maps to M, a shift of twelve, not the thirteen you might assume. Encryption added twelve, so I shift the target back by twelve with tr. The target decrypts to CAESAR IS EASY, the password for krypton three. One chosen plaintext, one encryption, and the key is exposed.
