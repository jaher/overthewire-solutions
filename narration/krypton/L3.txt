Krypton, level three. This is a simple substitution cipher, and unlike the last level we cannot query the encryption at all. But we have three intercepted English messages, all encrypted with the same key, plus the target. I log in as krypton three, read the README: the plaintexts are English and all four files share one key, so the break is one fixed substitution over one corpus, not a stepping one. I collect all four files into one working file and count the letter frequencies across the whole corpus: S thirteen percent, Q nine point six, J eight point five, U seven point three, B seven point zero, N six point eight. The hill-climb run recovers the mapping, and the key turns out to be the keyboard walk Q A Z W S X E D C R F V T G B Y H N U J M I K O L P read against A to Z. The target decrypts to WELL DONE THE LEVEL FOUR PASSWORD IS BRUTE, and the password is BRUTE, verified by logging in as krypton four. The same key also decrypts the intercepted messages, which is the cross-check that the key is right.
