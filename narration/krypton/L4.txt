Krypton, level four. Now the cipher is a Vigenere cipher with a key length of six. In a Vigenere cipher each letter is shifted by a different key letter, cycling every six characters, so the text splits into six interleaved Caesar ciphers. I log in as krypton four, and read the README. It works an example with the key GOLD: PROCEED MEETING AS AGREED encrypts to VFZFK SOPKS ELTUL VGUCH KR, adding letters modulo twenty-six. And it gives us the key length: six. I need the two intercepted messages as local files, so I open vim and write the first ciphertext into a file, one long line of five-letter groups. The file is seventeen hundred and forty-one bytes. The second message gets the same treatment: I open vim and write its ciphertext into a second file, another long line of five-letter groups. The second file is twenty-nine hundred and forty-four bytes. Then I read the target: HCIKV RJOX, nine letters in two groups. Now I write the solver. I open vim and type it in: The imports: re for the letter filter, and Counter for the tallies. The header comment states the plan: with a six-letter key the text splits into six columns, and the most frequent letter of each column is E, which fixes the key letter. Then the English letter frequency table the scoring measures against. First it strips each file down to just its capital letters, then, for each of the six key positions, it tries all twenty-six shifts and keeps the one whose decrypted column best matches English letter frequencies. Decoding just subtracts the key letter at each position, cycling every six. The main part reads both files and recovers the six key letters from the first file's columns. Then it prints the key, the first forty letters of each decoded message, and the decoded target. I run it. The key is FREKEY. The first message decodes to the start of an English sentence: THE SOLDIER WITH THE GREEN WHISKERS LED THEM, cut off at forty letters, and the second to THEY WERE OBLIGED TO CAMP OUT THAT NIGHT UNDER AL, also cut off at forty letters. The target decodes straight to CLEARTEXT, the password for krypton five. Both messages read as English under the same key, which is the confirmation the key is right.
