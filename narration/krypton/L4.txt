Krypton, level four. Now the cipher is a Vigenere cipher with a key length of six. In a Vigenere cipher each letter is shifted by a different key letter, cycling every six characters, so the text splits into six interleaved Caesar ciphers. We take the two intercepted messages separately, because each starts at the beginning of the key. For each of the six positions we try all twenty-six shifts and pick the one whose decrypted column best matches English letter frequencies. Both messages independently produce the same six-letter key. Decrypting the target with that key gives a string that is still ROT thirteen encoded, so we apply ROT thirteen and get the password, clear text. We verify by logging in as krypton five.
