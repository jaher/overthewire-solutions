# OverTheWire: Bandit — solutions

The full Bandit wargame (levels 0–33) solved from a DGX Spark ("DGX 5") on 2026-10-20.

- **Terminal replay site** (GitHub Pages): watch every level being solved in a shell, typed out live — commands, output, and the password each level yields.
- **Writeup**: [`bandit-writeup.md`](bandit-writeup.md) — per level: the goal, the technique and exact commands, and the password obtained.

The site is a single static `index.html` published by the GitHub Action in `.github/workflows/pages.yml` on every push to `main`.
